# CODS Court - Python Standalone 100% Offline

ระบบสร้างรายงานกระบวนพิจารณาคดีความศาลแบบ **100% Offline (Air-Gapped)**
พัฒนาด้วย **Python** ร่วมกับ **PySide6 (Qt)** ปราศจากการใช้งาน HTML/Web view หรืออินเทอร์เน็ตใดๆ

---

## คุณสมบัติเด่นของระบบ (Core Features)

1. **ระบบคลัง Template ย่อหน้าส่วนตัว (Personal Paragraph Templates)**
   - บันทึกและจัดการข้อความกระบวนพิจารณาสำเร็จรูปที่ใช้บ่อย (เช่น นัดพร้อม, สืบพยาน, ไกล่เกลี่ย, ฟังคำพิพากษา, ขอถอนฟ้อง)
   - สามารถแทรก Template นำข้อความมาใส่ในย่อหน้าได้ทันที
   - บันทึกข้อความในย่อหน้าเป็น Template เพื่อเก็บไว้ใช้ในครั้งต่อๆ ไป
   - ค้นหาและจัดหมวดหมู่ Template ได้ง่าย พร้อมระบบบันทึกถาวรลงไฟล์ในเครื่อง

2. **ระบบบันทึกและจับคู่คู่องค์คณะอัตโนมัติ (Bench Pairing System)**
   - เลือกหรือพิมพ์ชื่อ **ผู้พิพากษาคนที่ 1 (เจ้าของสำนวน)** แล้วชื่อ **ผู้พิพากษาคนที่ 2 (องค์คณะ)** จะขึ้นให้อัตโนมัติทันทีตามที่จับคู่ไว้
   - มีระบบจดจำการจับคู่ถาวร เปิดโปรแกรมครั้งต่อไปก็จำได้เสมอ
   - มีปุ่ม "จับคู่นี้ไว้" และหน้าต่าง "จัดการคู่องค์คณะ" สำหรับเพิ่ม แก้ไข หรือลบคู่ผู้พิพากษา

3. **ระบบจัดลำดับผู้มาศาลที่ใช้งานง่ายและคล่องตัว (Court Attendees & Signatories Manager)**
   - แสดงลำดับชัดเจน (ลำดับที่ 1, 2, 3...) รองรับ Drag & Drop ลากสลับตำแหน่งได้อิสระ
   - ปุ่มเลื่อนขึ้น, เลื่อนลง, ลบ สะดวก รวดเร็ว
   - ปุ่มลัดเพิ่มบทบาทมาตรฐานศาล (โจทก์, ทนายโจทก์, จำเลย, ทนายจำเลย, ฯลฯ)
   - ช่องกรอกเพิ่มชื่อหรือตำแหน่งผู้มาศาลอื่นๆ ได้ตามต้องการ
   - ปุ่มจัดเรียงตามธรรมเนียมปฏิบัติของศาลให้อัตโนมัติ
   - แสดงข้อความสรุปผู้มาศาลแบบ Real-time ("วันนี้...มาศาล") ตรงตามที่จะปรากฏในรายงาน Word จริง

4. **การแบ่งขั้นตอนการทำงานเป็น 3 ส่วน (Sequential 3-Section Wizard)**
   - **ส่วนที่ 1:** ข้อมูลคดีความและองค์คณะ (เลขดำ, เลขแดง, ศาล, ประเภทคดีพร้อม Autocomplete, วันเวลานัด, องค์คณะ)
   - **ส่วนที่ 2:** รายชื่อผู้มาศาล (Signatories)
   - **ส่วนที่ 3:** ย่อหน้ากระบวนพิจารณาเพิ่มเติม (เริ่มต้น 0 กล่องย่อหน้า สามารถกดสร้างไฟล์ Word ได้ทันที หรือกดเพิ่มย่อหน้าตามต้องการ)

5. **ระบบไอคอนแบบ Vector SVG และฟอนต์ Kanit**
   - ใช้งานไอคอน Vector SVG คมชัด ไม่แตก และไม่ใช้ Emoji
   - ฟอนต์ Kanit รองรับภาษาไทยอ่านง่าย เป็นทางการระดับ Enterprise Judicial Theme

## สถาปัตยกรรมและการจัดระเบียบโครงสร้างไฟล์ (Clean Architecture)

โปรแกรมได้รับการจัดแบ่งโฟลเดอร์และไฟล์อย่างเป็นระเบียบตามหลัก Modular Architecture:

```
jads-python/
├── ui/                              # Presentation Layer (ส่วนติดต่อผู้ใช้)
│   ├── theme.py                     # โหลดฟอนต์ Kanit และชุดสไตล์ทางการ (Official Judicial QSS)
│   ├── components/                  # คอมโพเนนต์ UI แบบแยกส่วน
│   │   ├── sidebar.py               # แถบเมนูนำทางด้านซ้ายและสถานะออฟไลน์
│   │   └── ...
│   └── pages/                       # หน้าจอแสดงผลแต่ละขั้นตอน (Wizard Pages)
│       ├── menu_page.py             # หน้าหลัก / Dashboard เมนูลัด
│       ├── import_page.py           # ขั้นตอนที่ 1: หน้าต่างนำเข้าไฟล์ตารางนัด Excel
│       ├── table_page.py            # ขั้นตอนที่ 2: ตารางแสดงรายการคดีและค้นหากรองข้อมูล
│       └── form_page.py             # ขั้นตอนที่ 3: แบบฟอร์ม 3 ส่วน และระบบสร้างไฟล์ Word
│
├── services/                        # Service Layer (บริการประมวลผลข้อมูล)
│   ├── excel_service.py             # จัดการอ่านไฟล์ Excel คัดกรองคอลัมน์ และจับคู่หัวตาราง
│   ├── docx_service.py              # จัดการสร้างและแทนที่ตัวแปรใน Word (.docx) 100% Offline
│   ├── storage_service.py           # จัดเก็บ Template, คู่องค์คณะ, และการตั้งค่าลง JSON
│   └── icon_service.py              # ตัวเรนเดอร์ไอคอน Vector SVG คมชัด 100%
│
├── constants.py                     # ค่าคงที่ส่วนกลาง (ประเภทคดี, ลำดับบทบาทผู้มาศาล)
├── ui_components.py                 # คอมโพเนนต์ ParagraphCard และ SignatoriesManagerWidget
├── dialogs.py                       # หน้าต่างโมดอลจัดการคู่องค์คณะและ Template
├── main.py                          # Application Entry Point ควบคุม State และการเชื่อมโยง Signals
├── data/                            # ข้อมูล JSON ในเครื่อง (Template, คู่องค์คณะ, ตั้งค่าศาล)
├── fonts/                           # ชุดฟอนต์ Kanit TTF
├── templates/                       # ไฟล์ต้นแบบรายงานกระบวนพิจารณา (.docx)
├── requirements.txt                 # รายการไลบรารีที่จำเป็น
└── run.bat                          # สคริปต์เปิดโปรแกรมแบบ 1-คลิก
```

## ⌨️ ระบบปุ่มคีย์ลัดและการควบคุมด้วยแป้นพิมพ์ (Keyboard Shortcuts Guide)

ระบบ CODS ได้รับการออกแบบตามหลัก **Keyboard-First Design** เพื่อให้เจ้าหน้าที่ธุรการศาลและนิติกรสามารถปฏิบัติงานได้อย่างรวดเร็ว คล่องตัว และแม่นยำ โดยไม่ต้องละมือจากแป้นพิมพ์มาจับเมาส์บ่อยครั้ง

### 1. ปุ่มคีย์ลัดที่ใช้ร่วมกับ CTRL (Ctrl-based Shortcuts)

| คีย์ลัด (Shortcut) | หน้าต่าง / ตำแหน่งที่ใช้งาน | หน้าที่และการทำงาน (Description) |
| :--- | :--- | :--- |
| **`Ctrl + O`** | ทุกหน้าจอ / ขั้นตอนที่ 1 | **เปิดหน้าต่างเลือกไฟล์ Excel:** เปิด File Dialog เพื่อเลือกไฟล์ตารางนัดพิจารณาคดีความ (.xlsx) มานำเข้าสู่ระบบทันที |
| **`Ctrl + F`** | ทุกหน้าจอ / ขั้นตอนที่ 2 | **ค้นหาคดีความ:** กระโดด Focus ไปยังช่องค้นหาในตารางนัดพิจารณาคดี เพื่อกรองเลขดำ เลขแดง หรือชื่อคู่ความได้ทันที |
| **`Ctrl + S`** | ขั้นตอนที่ 3 (แบบฟอร์ม) | **สร้างรายงาน Word:** สั่งประมวลผลและสร้างไฟล์รายงานกระบวนพิจารณา Microsoft Word (.docx) ตามแบบพิมพ์ ๒๒ ทันที |
| **`Ctrl + T`** | ทุกหน้าจอ | **คลัง Template ย่อหน้า:** เปิดหน้าต่างโมดอลจัดการ Template ย่อหน้าส่วนตัว (เพิ่ม, แก้ไข, ลบ หรือจัดหมวดหมู่ข้อความสำเร็จรูป) |
| **`Ctrl + B`** | ทุกหน้าจอ | **จัดการคู่องค์คณะ:** เปิดหน้าต่างจัดการคู่ผู้พิพากษาเจ้าของสำนวนและองค์คณะ (Bench Pairing Manager) |
| **`Ctrl + H`** | ทุกหน้าจอ | **กลับหน้าหลัก (Home):** ย้อนกลับสู่หน้าแรก / เมนูหลักและแดชบอร์ด |
| **`Ctrl + 1`** | ทุกหน้าจอ | **ไปขั้นตอนที่ 1:** กระโดดไปยังหน้าต่างนำเข้าไฟล์ตารางนัด Excel |
| **`Ctrl + 2`** | เมื่อมีข้อมูลตารางนัด | **ไปขั้นตอนที่ 2:** กระโดดไปยังหน้าตารางรายการคดีและการค้นหา |
| **`Ctrl + 3`** | เมื่อเลือกคดีแล้ว | **ไปขั้นตอนที่ 3:** กระโดดไปยังหน้าแบบฟอร์ม 3 ส่วน และการส่งออก Word |

### 2. ปุ่มฟังก์ชันและปุ่มนำทางขั้นตอนงาน (Function & Navigation Keys)

| ปุ่มกด (Key) | หน้าที่และการทำงาน (Description) |
| :--- | :--- |
| **`F1`** | **เปิดคู่มือสรุปคีย์ลัดทั้งหมด:** แสดงหน้าต่าง Modal Cheat Sheet สรุปปุ่มลัดทั้งหมดในโปรแกรม |
| **`F5`** | **สร้างรายงาน Word (.docx):** ทำงานเทียบเท่ากับ `Ctrl + S` สำหรับสั่งส่งออกไฟล์เอกสารในขั้นตอนที่ 3 |
| **`PageDown (PgDn)`** | **ไปขั้นตอนถัดไป / Section ถัดไป:** เลื่อนลำดับการทำงานไปข้างหน้าตามลำดับ Wizard |
| **`PageUp (PgUp)`** | **ย้อนกลับขั้นตอนก่อนหน้า / Section ก่อนหน้า:** ถอยกลับไปยังหน้าจอก่อนหน้า |

### 3. การควบคุมระบบเติมคำอัตโนมัติด้วยแป้นพิมพ์ (Judicial Autocomplete Navigation)

ในช่องกรอกข้อมูลศาล, ประเภทคดี, และชื่อผู้พิพากษา:
- **`คลิก / Tab เข้าช่อง`**: รายการคำแนะนำศาลหรือรายชื่อผู้พิพากษาจะเปิดขึ้นทันทีโดยอัตโนมัติ
- **`ลูกศรลง (↓) / ลูกศรขึ้น (↑)`**: เลื่อนแถบไฮไลต์เลือกรายการคำแนะนำ
- **`Enter` หรือ `Tab`**: ยืนยันการเลือก และเติมข้อความลงในช่องทันทีพร้อมปิด Dropdown
- **`Escape (Esc)`**: ปิดแถบรายการคำแนะนำ

## 🚀 วิธีการใช้งานและการติดตั้งโปรแกรม (Deployment & Installation)

ระบบ CODS ใช้ **Inno Setup** เป็นระบบติดตั้งมาตรฐานหลักขององค์กร:

### 1. ติดตั้งและอัปเดตลงเครื่อง (Inno Setup Installer)
เหมาะสำหรับเครื่องคอมพิวเตอร์ประจำโต๊ะทำงานที่ต้องการความสะดวกและรวดเร็ว:
- **ติดตั้ง/อัปเดต:** ดับเบิลคลิกที่ไฟล์ **`dist_installer\CODS_Setup_v1.1.exe`**
- **สิทธิ์ Non-Admin:** ติดตั้งลงใน `%LOCALAPPDATA%\Programs\CODS` ได้ทันที ไม่ต้องใช้สิทธิ์ Administrator
- **ระบบ Auto-Update:** หากมีเวอร์ชันเดิมติดตั้งอยู่แล้ว ระบบจะเข้าสู่โหมดอัปเดตเวอร์ชันให้อัตโนมัติ โดยสำรองข้อมูลและคงฐานข้อมูลคดี (SQLite) รวมถึงแม่แบบส่วนตัวไว้ 100% ไม่สูญหาย
- **ทางลัดพร้อมใช้งาน:** สร้างไอคอนทางลัด **CODS** บนหน้าจอ Desktop และ Start Menu อัตโนมัติ
- **ถอนการติดตั้ง:** ถอนการติดตั้งผ่าน Windows Settings หรือเมนู Uninstall CODS ใน Start Menu ได้อย่างหมดจด

### 2. รันจากซอร์สโค้ด Python (Developer Mode)
1. ติดตั้งไลบรารีที่จำเป็น:
   ```cmd
   pip install -r requirements.txt
   ```
2. ดับเบิลคลิกที่ไฟล์ **`run.bat`** หรือรันคำสั่ง:
   ```cmd
   python main.py
   ```

## 🛠️ การคอมไพล์และสร้างตัวติดตั้ง Inno Setup (Building from Source)

หากมีการแก้ไขโค้ดหรืออัปเดตแม่แบบ และต้องการสร้างตัวติดตั้ง Inno Setup ชุดใหม่:
- ดับเบิลคลิกที่ไฟล์ **`build_inno.bat`**
- ระบบจะตรวจสอบและคอมไพล์ไบนารีผ่าน `cods.spec` และคอมไพล์ `installer_inno.iss` ออกมาเป็นตัวติดตั้ง `dist_installer\CODS_Setup_v1.1.exe` ทันทีในคลิกเดียว
